## 2026-11-22: Outreach Today view, one Start button to work through waiting replies (#1090)

Engage › Outreach used to show where each channel's five stages stood, but approving the replies waiting for you meant opening each channel's own screen. Now every channel opens with a **Today** box, and an **All channels** tab shows all three together. One line says what is waiting ("3 replies waiting for you · 12 new conversations · Mini signed in"). One button, **Start**, then shows the waiting replies one after another, oldest first. Press 1, 2 or 3 to choose an option, E to edit it, A to approve, R to reject (it asks why first), or the right arrow to skip.

Approving or rejecting here does exactly what the channel's own screen does, using the same server calls, and nothing is posted by this change: the Mini still posts approved replies at its normal pace. Any number that could not be counted says "cannot tell" instead of showing 0, so an empty line never hides a broken one.
