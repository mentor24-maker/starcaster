## 2026-11-19 — Write each video's YouTube title and description (Reel Spinner 6a) (#1082)

Every rough cut on Assets › Footage › Rough cuts now comes with a YouTube
title, description and tags, written by the Mac Mini. It writes them from the
words the video actually keeps, Dane's Reel Spinner notes, and the project
the video's end card invites people to. The aim is people who might work with
him, not clicks: anything begging for likes or subscribes is refused.

The end of every description is fixed and is not the AI's to write: the end
card's invitation and web address, then the music credit when the music
needs one. The program adds them, so they can't go missing.

Dane can change any box on the card. The Mini only ever fills an empty box,
so his words are never overwritten. **Approve** sends whatever is in the
boxes. When a box is empty, the card says why (for example, no end card
written for that project yet).
