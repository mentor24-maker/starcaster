## 2026-11-17 — Show each recording's scored moments on Footage (Reel Spinner 2e) (#1032)

Reel Spinner scores each recording for the moments worth sharing, but until
now there was nowhere to see those scores. Assets › Footage now has a
**Moments** switch beside a recording's transcript. It shows a short summary
and then each moment, best first: its score, when it starts, how long it
runs, which project it speaks to, the quote, and why it scored well. Each one
has a link that opens the recording in Google Drive, with the start time
written beside it.

If you edit the notes Reel Spinner reads (Assets › Context) after a recording
was scored, the screen says the score is out of date and offers **Score
again**. Pressing it leaves a request for the Mac Mini, and the screen says
it is waiting for the Mini. When there is nothing to show, the screen always
says why: not scored yet, scoring failed (and the reason), no notes switched
on for Reel Spinner (with a link to switch one on), or the notes could not be
read. Each project only ever sees its own recordings.
