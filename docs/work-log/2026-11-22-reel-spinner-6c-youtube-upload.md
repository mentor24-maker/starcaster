## 2026-11-22 — Upload finished videos to YouTube as Private (Reel Spinner 6c) (#1089)

The last step of Reel Spinner. When the Mac Mini finishes a video Dane approved, it now uploads it to the Dane of Earth channel as Private, with the title, description and tags he approved. It never makes a video public; the Rough cuts card shows "on YouTube (private)" with a link to YouTube Studio, where he makes it public with one click.

Why it matters: these files can be gigabytes, so a dropped connection carries on from where YouTube got to instead of starting again, and a retry never uploads the same video twice. The copy on the Mini is deleted only after YouTube shows the video and the database records it. A used-up daily allowance waits for the reset, a refused sign-in tells the bus how to fix it, and a video YouTube refuses stays on the card with YouTube's reason instead of disappearing.

Not done yet: the first real upload. It happens on its own once this is merged and the Studio worker on the Mini restarts.

Fixed after review: YouTube reports the channel's daily upload cap as a "bad request" (code 400), and the first version read that as YouTube refusing the video, so approved videos would have been marked failed instead of waiting for the reset. Now it waits. A video that cannot go up now says plainly that nothing more happens to it on its own (the screen has no button to send it again yet), and a missing file is described as a missing file rather than as YouTube refusing it. The channel is checked every time a new upload starts, a video YouTube rejects is not re-read on every retry, a confused upload can no longer loop forever, and old unrelated failures can no longer push cards off the Rough cuts screen.

Fixed after the second review: a video YouTube refused could be quietly re-made and put back in "waiting for review" when a sister short from the same recording was sent back, losing Dane's approval. Those videos are now left exactly where the upload stopped. A video already up on YouTube no longer gets stuck if the music shelf or end card changed since; it only finishes the paperwork. A rejected video's note is kept until the database has recorded the rejection, so a hiccup cannot cause a second full upload. A job that failed every try is no longer re-tried every six hours forever. A wrong-channel sign-in can no longer reset the alarm's quiet period and message the bus every hour. And the "more than one read" note now says what really happens.
