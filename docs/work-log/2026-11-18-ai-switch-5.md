## 2026-11-18 — Move the messaging, theme and page-import features onto the AI door and block new direct calls (AI switch 5) (#1064)

When Anthropic's credit ran out on 2026-10-30, most of the site's AI features stopped at once, even though OpenAI was paid for and ready. The reason was that each feature phoned Anthropic its own way. Over five tickets, every feature has been moved onto one shared "AI door". The door tries whichever provider is first on Settings › APIs › AI provider, and moves on to the next one if that provider is out of credit.

This is the last of those moves. These features now go through the door: Messaging's content and topic suggestions, the format converter (for example, turning a tweet into hashtags), the keyword and tag imports from web pages, the tool that sorts discovered websites into competitors and models, and the contact "persona" writer. They ask the same questions as before; they just no longer care which company answers.

There is also a new guard, `npm run check:ai-door`. If anyone writes code that calls an AI company directly instead of going through the door, it refuses the commit and the pull request. It names the file and line, and says what to use instead.

Two features could not move yet: the Theme Wizard and the flyer upload (turning a program flyer into events). Both have the AI look at a picture, a PDF or a web page, and the door can only send text today. The guard lists them by name every time it runs, and ticket SC-895 will teach the door to send pictures and PDFs. That ticket also asks Dane a question: should the Theme Wizard keep insisting on Claude for its design taste?
