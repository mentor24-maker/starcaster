## 2026-11-18 — Move the eight features that ask for Claude by name onto the AI door (AI switch 3) (#1059)

The ticket named eight features. Three of them, the outreach reply writers,
were split off and moved earlier today by SC-884, and Reel Spinner's scoring
was already on the door, so this change moves the remaining five.

Those five asked for Claude by name, so they could only ever spend
Anthropic's credit, and stopped whenever that account ran dry: Reddit
subreddit suggestions, Substack Miner's wider keywords, the Substack and
YouTube "suggest a decision" pass, font auto-tagging, and outreach lessons.

Each now asks through the AI door, the one place that picks a provider from
the order on Settings › APIs › AI provider and moves on to the next when one
cannot pay. Each says how big a model it needs ("fast" for fonts, "strong"
for the rest) instead of naming one. Their prompts are unchanged, and the AI
spend meter still files each call under the same feature name. The
suggestion records now say which model actually answered.

**One model change to know about:** outreach lessons used to get Claude
Opus 4.8 by default. On the "strong" tier it now gets Claude Sonnet 5.5 when
Anthropic answers (or GPT-5.5 when OpenAI does).

**And one stop that had to be rewired:** the Substack/YouTube suggest pass
stops the whole run when no AI provider can answer (no key, no credit), so it
does not read every writer's posts only to fail each one. It used to spot
that by the old wording of Anthropic's error, which the door does not use, so
it would have kept going. It now reads the door's own "no provider" signal,
and the Substack Miner and YouTube creators screens show "Stopped: …" again.

A new test plays each feature a recorded answer from Anthropic and then from
OpenAI, and checks the feature gets something usable out of both. Another
runs the suggest pass through the real door with no keys at all and checks it
stops after the first writer. Putting any of the old code back makes them fail.
