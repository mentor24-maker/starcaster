# Font library starter pack (Font Library 4/7, task 86bchyd4a)
#
# One Fontsource id per line (the id in https://fontsource.org/fonts/<id>),
# optionally followed by the weights to keep, e.g. "orbitron 400,700,900".
# With no weights listed the import keeps regular (400) and bold (700) where
# the family has them, or its one weight nearest regular, plus italics.
#
# Import:  npm run fonts:import -- docs/fonts/starter-pack.txt          (dry run)
#          npm run fonts:import -- docs/fonts/starter-pack.txt --apply
# Re-running is safe: families already in the library are left alone, so
# adding a line here and running it again imports just that line.
